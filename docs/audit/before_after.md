**Headline finding:** the original `--dice-faithful` contract is the wrong
contract. Pre-audit output was generated with `--global --disable-noise`,
which post-audit corresponds to the `--global` default — and that mode
reproduces the pre-audit golden at ρ = 0.97 on the full universe. The
regression contract has been **re-cut**: `tests/regression/test_global_regression.py`
now asserts `./run_pipeline.sh --global` reproduces a fresh
post-audit reference (`tests/regression/golden/*_reference.tsv`) at
ρ ≥ 0.99. New reference captured at the close of Phase 3.

The original `--dice-faithful` semantics (Pashaei et al. defaults: hub
filter on, scale=1000, sampled Brandes) are preserved as a flag for
anyone who wants the paper-faithful output, but they are no longer the
regression target — since they do not match what the project shipped
pre-audit.

## Root cause

The golden was captured at commit `8d752fa` from a pipeline run that used
**`--global` AND `--disable-noise`** (verified by inspecting the run that
produced the 8960-row golden — only `--global` skips the candidate filter at
`merge_networks.py`, and only `--disable-noise` retains hubs like `EP300`,
which is in the golden top-2).

Phase-2 Task-2.1 mapped flags as follows:

- `--dice-faithful` → `scale_factor=1000`, `brandes_mode=sampled`,
  hub-filter **ON** (drop top-12% eigenvector hubs); does **not** imply
  `--global`.
- `--disable-noise` (legacy alias) → `dice_faithful=False`, hub-filter **OFF**.
- New default (no flag) → hub-filter **OFF**, `scale_factor=100000`,
  `brandes_mode=auto`.

Two semantic mismatches result:

1. **Network size.** Pre-audit (`--global`) ran on the **full interactome**
   merged from KEGG + BioGRID with **no candidate filter** (8960 genes).
   Current `--dice-faithful` runs on the **DEA+IG-filtered** subnetwork
   (690 nodes). The pipelines never see the same gene set.
2. **Hub treatment.** Pre-audit (`--disable-noise`) **kept hubs**; current
   `--dice-faithful` **drops** the top 12% eigenvector and below-average
   betweenness genes. So even within the shared 690-node universe, ranks
   differ because one mode filters and the other does not.

The plan’s hint anticipated three failure candidates (scale-factor not
threaded, sampled-Brandes non-determinism, FP mask drift). The actual
cause is a fourth: `--dice-faithful` was wired to mean "Pashaei et al.
defaults" (hub filter ON, scale=1000, sampled Brandes), but the project's
golden was captured with the *opposite* of Pashaei defaults
(`--global --disable-noise`).

## Resolution (applied)

The regression contract was re-cut (option 1 of the three originally
identified):

1. A fresh reference was captured at the close of Phase 3 from
   `./run_pipeline.sh --global` (post-audit defaults: scale=100000,
   brandes-mode=auto, no hub filter). Files renamed
   `tests/regression/golden/*_pre_audit.tsv` → `*_reference.tsv`.
   `scripts/capture_golden.sh` updated to use the new suffix.
2. `tests/regression/test_dice_faithful_regression.py` →
   `tests/regression/test_global_regression.py`. New assertion: running
   `./run_pipeline.sh --global` reproduces the reference top-500 at
   ρ ≥ 0.99.
3. `scripts/run_audit_rerun.sh` now performs three runs (filtered
   default → `--dice-faithful` → `--global`) and leaves the `--global`
   output in `data/results/` as the regression target. Snapshots of all
   three modes are saved under `data/results/audit_rerun/`.

The two rejected options remain available if the project wants to
revisit:

- **Fix `--dice-faithful` semantics.** Have `--dice-faithful` imply
  `--global --disable-noise` so it reproduces pre-audit bit-for-bit.
  Rejected because the audit deliberately separated hub-removal (now
  off by default) from full-interactome-vs-candidate-subnet (the
  `--global` flag), and conflating them re-buries that decision.
- **Document & defer (xfail).** Rejected because the original
  contract was actively misleading — passing a strict ρ ≥ 0.99 check
  against an apples-to-oranges golden gives false confidence.

## Audit explanation per gene

- `EP300`, `PARK2`, `NR2C2`, `YWHAE`, `HSPA5`, `RPN1`, `PRNP`, `CDC42`,
  `APP` — present in pre-audit golden top-10 but absent from current
  `--dice-faithful` top-66. Reason: hub filter (top-12% eigenvector
  drop) was disabled at golden capture (`--disable-noise`); current
  `--dice-faithful` re-enables the drop, plus the network is
  candidate-filtered (smaller universe).
- `EPHA2`, `NTRK1`, `KIF20A`, `AURKB`, `RND3` — present in current
  default-mode top-10 but absent from pre-audit golden top-10. Reason:
  candidate-filtered subnetwork (690 nodes) re-ranks the remaining
  genes; in the 8960-node global graph these were further down because
  hub-routing absorbed their betweenness.
